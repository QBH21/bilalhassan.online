Questions people ask

What's an API integration?

It's how two systems talk. Your site asks another service for something, like prayer times, a payment or a map, and gets back an answer your code can use.

Can you connect to a service you haven't used before?

Usually, yes. Most APIs follow the same patterns. I read the documentation before I quote, and I'll tell you if anything looks risky.

What happens when the other service is down?

A good integration plans for it with timeouts, retries and a fallback, so your page still works. The prayer times demo above falls back to a saved response if the live request fails.
